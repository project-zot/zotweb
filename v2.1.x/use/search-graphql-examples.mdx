description: "Example GraphQL queries for searching images, repositories, CVEs, and referrers in zot."

---

Each example shows the GraphQL query and a trimmed response. Responses use real field names from the zot schema, and `...` marks content that's cut for length.

<Note>
  To send a query, see [Search with GraphQL](/v2.1.x/use/search-graphql#send-a-query). The queries request many fields. You can request a subset and omit what you don't need.
</Note>

To run any query from a shell, wrap it in a JSON body:

```bash
curl -X POST -H "Content-Type: application/json" \
  --data '{ "query": "{ ImageList(repo: \"ubuntu\") { Results { Tag Digest } } }" }' \
  http://localhost:5000/v2/_zot/ext/search
```

## Find images

<AccordionGroup>
  <Accordion title="List all images in a repository" defaultOpen>
    Use `repo: ""` to list images from every repository.

    ```graphql
    {
      ImageList(repo: "ubuntu") {
        Results {
          Tag
          Digest
          LastUpdated
          Size
        }
      }
    }
    ```

    ```json
    {
      "data": {
        "ImageList": {
          "Results": [
            {
              "Tag": "jammy",
              "Digest": "sha256:f96fcb040c7ee00c037c758cf0ab40638e6ee89b03a9d639178fcbd0e7f96d27",
              "LastUpdated": "2022-10-14T15:29:18.0325322Z",
              "Size": "30472739"
            },
            {
              "Tag": "latest",
              "Digest": "sha256:9bc6d811431613bf2fd8bf3565b319af9998fc5c46304022b647c63e1165657c",
              "LastUpdated": "2022-10-14T15:26:59.6707939Z",
              "Size": "30472740"
            }
          ]
        }
      }
    }
    ```
  </Accordion>

  <Accordion title="Search by name, or by repository and tag">
    A plain string searches repository names. A string with a colon searches tags.

    ```graphql
    {
      GlobalSearch(query: "ubuntu:latest") {
        Page {
          ItemCount
          TotalCount
        }
        Images {
          RepoName
          Tag
          LastUpdated
          Manifests {
            Digest
            Layers {
              Size
              Digest
            }
          }
        }
      }
    }
    ```

    ```json
    {
      "data": {
        "GlobalSearch": {
          "Page": {
            "ItemCount": 1,
            "TotalCount": 1
          },
          "Images": [
            {
              "RepoName": "ubuntu",
              "Tag": "latest",
              "LastUpdated": "2022-10-14T15:26:59.6707939Z",
              "Manifests": [
                {
                  "Digest": "sha256:9bc6d811431613bf2fd8bf3565b319af9998fc5c46304022b647c63e1165657c",
                  "Layers": [
                    {
                      "Size": "30428928",
                      "Digest": "sha256:cf92e523b49ea3d1fae59f5f082437a5f96c244fda6697995920142ff31d59cf"
                    }
                  ]
                }
              ]
            }
          ]
        }
      }
    }
    ```

    To list repositories instead, request `Repos`. An empty query matches every repository:

    ```graphql
    {
      GlobalSearch(query: "") {
        Repos {
          Name
        }
      }
    }
    ```

    ```json
    {
      "data": {
        "GlobalSearch": {
          "Repos": [
            { "Name": "centos" },
            { "Name": "ubuntu" }
          ]
        }
      }
    }
    ```
  </Accordion>

  <Accordion title="Find images that contain a digest">
    Matches a manifest, config, or layer digest.

    ```graphql
    {
      ImageListForDigest(
        id: "79eae04a0e32878fef3f8c5f901c32f6704c4a80b7f3fd9d89629e15867acfff"
      ) {
        Results {
          RepoName
          Tag
          Title
        }
      }
    }
    ```

    ```json
    {
      "data": {
        "ImageListForDigest": {
          "Results": [
            {
              "RepoName": "ubuntu",
              "Tag": "kinetic-20220922",
              "Title": "ubuntu"
            }
          ]
        }
      }
    }
    ```
  </Accordion>

  <Accordion title="Find images built on or from an image">
    `DerivedImageList` returns images that use the given image as a base. `BaseImageList` returns the images it depends on.

    <CodeGroup>
      ```graphql DerivedImageList
      {
        DerivedImageList(image: "ubuntu:latest", requestedPage: {offset: 0, limit: 10}) {
          Page {
            TotalCount
            ItemCount
          }
          Results {
            RepoName
            Tag
            LastUpdated
          }
        }
      }
      ```

      ```graphql BaseImageList
      {
        BaseImageList(image: "mariadb:latest", requestedPage: {offset: 0, limit: 10}) {
          Page {
            TotalCount
            ItemCount
          }
          Results {
            RepoName
            Tag
            LastUpdated
          }
        }
      }
      ```
    </CodeGroup>

    Response for `BaseImageList`:

    ```json

      "data": {
        "BaseImageList": {

              "Tag": "latest",
              "LastUpdated": "2022-10-14T18:26:59.6707939+03:00"
            }
          ]
        }
      }
    }
    ```
  </Accordion>
</AccordionGroup>

  <Accordion title="What the Image fields mean">
    **Identity**

    - `RepoName`, `Tag`, `Digest`: the resolved reference. `Digest` is the digest of the manifest or index.
    - `MediaType`: the media type of that object, for example a manifest or an index.
    - `ArtifactType`: for a manifest, the `artifactType` field if present, otherwise the config media type. For an index, the index `artifactType`.

    **Size and popularity**

    - `Size`: total size in bytes, returned as a string. It covers the manifest, config, and layers.
    - `DownloadCount`: how many times zot recorded a pull of this image's manifest.

    **Timestamps**

    - `PushTimestamp`: when the image was pushed to the registry.
    - `TaggedTimestamp`: when the tag was applied. If that isn't recorded, it falls back to the push time.
    - `LastPullTimestamp`: the last pull. For an image that was never pulled, the value is a default timestamp. The sample shows the Unix epoch.
    - `LastUpdated`: when the image was last modified, from the config or the most recently updated layer.

    **Descriptive metadata**

    `Description`, `Title`, `Documentation`, `Licenses`, `Source`, `Vendor`, and `Authors` come from image annotations when present. `Labels` is currently unused.

    **Security and policy**

    - `IsSigned` and `SignatureInfo { Tool IsTrusted Author }`: signature status. See [Verify image signatures](/v2.1.x/security/signatures).
    - `Vulnerabilities`: counts by severity. These are filled only when [CVE scanning](/v2.1.x/security/cve-scanning) is enabled and results are available.
    - `IsDeletable`: whether the current user can delete this tag. It can be `null` when delete permission isn't evaluated.

    **Referrers**

    `Referrers` lists artifacts that point at the image, such as signatures and SBOMs. Each has `MediaType`, `ArtifactType`, `Size`, `Digest`, and `Annotations`.

    **Manifests**

    One entry per platform for an index, or a single entry for a single-architecture image. It repeats `IsSigned`, `SignatureInfo`, `Vulnerabilities`, `DownloadCount`, and `Referrers` for that manifest, and adds `ConfigDigest`, `Platform { Os Arch }`, `Layers { Size Digest }`, and `History`. A history entry with `EmptyLayer: true` didn't change the filesystem.
  </Accordion>

  <Accordion title="Find referrers of an image">
    Returns artifacts that have the given digest as their `subject`. The `type` argument filters by artifact type.

    ```graphql
    {
      Referrers(
        repo: "golang"
        digest: "sha256:fed08b0eaea00aab17f82ecbb78675919d216c72eea985581758191f694aeaf7"
        type: "application/vnd.example.icecream.v1"
      ) {
        MediaType
        ArtifactType
        Digest
        Annotations {
          Key
          Value
        }
      }
    }
    ```

    ```json
    {
      "data": {
        "Referrers": [
          {
            "MediaType": "application/vnd.oci.artifact.manifest.v1+json",
            "ArtifactType": "application/vnd.example.icecream.v1",
            "Digest": "sha256:be7a3d01c35a2cf53c502e9dc50cdf36b15d9361c81c63bf319f1d5cbe44ab7c",
            "Annotations": [
              { "Key": "format", "Value": "oci" },
              { "Key": "demo", "Value": "true" }
            ]
          }
        ]
      }
    }
    ```
  </Accordion>
</AccordionGroup>

## Search by vulnerability

These queries need [CVE scanning](/v2.1.x/security/cve-scanning) to be enabled.

<AccordionGroup>
  <Accordion title="List the CVEs of an image" defaultOpen>
    The example sorts by severity and asks for the second CVE only. You can also filter with `severity`, `searchedCVE`, and `excludedCVE`.

    ```graphql
    {
      CVEListForImage(
        image: "alpine:3.17"
        requestedPage: {limit: 1, offset: 1, sortBy: SEVERITY}
      ) {
        Tag
        Page {
          TotalCount
          ItemCount
        }
        CVEList {
          Id
          Title
          Description
          Severity
          PackageList {
            Name
            InstalledVersion
            FixedVersion
          }
        }
      }
    }
    ```

    ```json
    {
      "data": {
        "CVEListForImage": {
          "Tag": "3.17",
          "Page": {
            "TotalCount": 9,
            "ItemCount": 1
          },
          "CVEList": [
            {
              "Id": "CVE-2023-5363",
              "Title": "openssl: Incorrect cipher key and IV length processing",
              "Description": "Issue summary: A bug has been identified in the processing of key and initialisation vector (IV) lengths. ...",
              "Severity": "HIGH",
              "PackageList": [
                {
                  "Name": "libcrypto3",
                  "InstalledVersion": "3.0.8-r0",
                  "FixedVersion": "3.0.12-r0"
                },
                {
                  "Name": "libssl3",
                  "InstalledVersion": "3.0.8-r0",
                  "FixedVersion": "3.0.12-r0"
                }
              ]
            }
          ]
        }
      }
    }
    ```

    `Severity` is one of `UNKNOWN`, `LOW`, `MEDIUM`, `HIGH`, or `CRITICAL`.
  </Accordion>

  <Accordion title="Compare the CVEs of two images">
    `CVEDiffListForImages` returns CVEs that are in the `minuend` image but not in the `subtrahend` image. It's useful for checking that a new image fixes what the old one had.

    ```graphql
    {
      CVEDiffListForImages(
        minuend: {Repo: "alpine", Tag: "3.17"}
        subtrahend: {Repo: "alpine", Tag: "3.18"}
        requestedPage: {limit: 10, offset: 0}
      ) {
        Minuend {
          Repo
          Tag
        }
        Subtrahend {
          Repo
          Tag
        }
        Summary {
          Count
          MaxSeverity
        }
        Page {
          TotalCount
          ItemCount
        }
        CVEList {
          Id
          Severity
        }
      }
    }
    ```

    The response has the shape `data.CVEDiffListForImages` with the requested fields. For a multi-architecture image, add `Platform: {Os: "linux", Arch: "amd64"}` or a `Digest` to the image input to pick one manifest.
  </Accordion>
</AccordionGroup>
