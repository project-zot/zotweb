**zot** is an open-source container image registry server based purely on [OCI](https://opencontainers.org/) standards. It stores images in the OCI image layout and speaks the OCI Distribution Specification on the wire, so any compliant client works with it.

<Info>
  zot = OCI Distribution Specification + OCI image format. Everything else is an optional extension.
</Info>

## What is an OCI image registry?

An OCI image registry is a server that stores, manages, and shares container images. A developer pushes an image to the registry. Other users and systems pull it to run it. The [OCI Distribution Specification](https://github.com/opencontainers/distribution-spec) defines the standard HTTP API for these operations.

You can host zot on a public or private server as part of your CI/CD pipeline. In its minimal form, you can also embed zot in a product. In both cases zot gives you a secure software supply chain for container images.

## Why zot?

zot is built for developers by developers.
