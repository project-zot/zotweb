The OCI-native container registry

zot is a production-ready, vendor-neutral registry. One binary, no root privileges, and built-in search, signatures, scanning, and sync.

Quickstart Read the docs 
# run zot, then push an image
docker run -d -p 5000:5000 ghcr.io/project-zot/zot:latest
skopeo copy --dest-tls-verify=false \
  docker://alpine:latest docker://localhost:5000/alpine:latest

Everything a registry should do

Standards-based at the core, with optional extensions you turn on when you need them.

O

OCI-native

Conforms to the OCI Distribution Spec and stores images in OCI image layout.

1

Single binary

All features ship in one binary that runs without root.

S

Signed and scanned

Verify cosign and notation signatures and scan images for CVEs.

Q

Search and UI

Query images with GraphQL, browse them in a web UI, or use the zli CLI.

M

Sync and mirror

Pull through and mirror from other registries, on demand or on a schedule.

H

Scale and secure

Scale out, use S3, GCS, or Azure storage, and protect access with OIDC, LDAP, and mTLS.
